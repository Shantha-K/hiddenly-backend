# Node.js Backend API Project

This project is a Node.js backend API using Express.js, MongoDB, and follows the MVC architecture.

## Features
- Express.js REST API
- MongoDB integration via Mongoose
- MVC folder structure

## Getting Started

### Prerequisites
- Node.js (v16 or higher recommended)
- npm
- MongoDB (local or Atlas)

### Installation
```sh
npm install
```

### Running the Server
```sh
npm start
```

### Folder Structure
- `/controllers` - Route logic
- `/models` - Mongoose models
- `/routes` - API endpoints
- `/config` - Database config
- `/app.js` - Main app entry

## Customization
Add your models, controllers, and routes as needed for your application.
